# Калькулятор отметок (Tanks Blitz)

Считает, сколько боёв нужно до 1, 2 или 3 отметки на стволе, по общему среднему урону и темпу текущей сессии.

- `index.html` — сам сайт.
- `data.js` — планки урона для X, IX и VIII уровней с blitzhata.ru/marks.
- `scripts/update_marks.py` — скрипт, который забирает свежие планки.
- `.github/workflows/update.yml` — каждый понедельник запускает скрипт и обновляет сайт на GitHub Pages.

Обновить вручную: вкладка **Actions** → «Обновить планки и сайт» → **Run workflow**.

Если blitzhata поменяет вёрстку, скрипт остановится, старые планки останутся на сайте, а GitHub пришлёт письмо об ошибке.
